# Exact installed bridge module inspection

This explicit main-only action reads Cloudflare control metadata and the existing Hub module. It does not invoke a Worker or query D1. Before any Cloudflare request it requires an exact successful connected common-cloud run at the current main, the owner-authorized active105 phase, inactive fence, a matching live scoped owner and ten minutes of lease headroom.

The immutable release receipt is pinned by its complete raw SHA256. The current active version, deployment, module bytes, prefix, complete effective settings and crons must match it. The content endpoint must name the active latest upload before and after reading. Independent final deployment/settings/crons checks and another fresh main/lease/fence guard prevent a moved version from receiving an exact proof.

The control client only accepts GET for this account and this Hub's deployments, settings, schedules, exact version metadata, latest version listing and module content. It rejects bodies and unknown routes before fetch, follows no redirects and permits at most20 Cloudflare requests and40 GitHub requests. Both use the existing164 whole-job budget and preserve24 manual requests. Metadata responses are bounded to262144 bytes; multipart module content to6500000 bytes and the selected UTF8 module to4000000 bytes. No settings values or credentials are exported. A module containing an exact environment credential is refused. The successful artifact retains gzip-compressed original module bytes and separate raw/gzip digests.

This read-only provenance evidence does not observe a native SQL reply, qualify counter semantics, close a day, restore a report or free physical space. It changes no upload, activation, settings, cron, source, quota, SQL, storage format, pause or strategy. The existing UTC16 maintenance prohibition still applies. Missing credentials refuse locally and retain a zero-call failure receipt.

The new controlled checks cover wrong active/dormant versions, setting drift, wrong source/prefix, secret export, lease refusal, transport bounds and mutation refusal. Existing accepted native collector/hourly point receipts are reused rather than repeated.
