# Одна облачная проверка после сброса суток

Продолжение поручено владельцем15Oct без дополнительных команд, в облаке.
До UTC16 все четыре слота обслуживания UTC15 уже использованы; пятый не даётся.

`Report2 one bounded native storage qualification` запускается оператором один
раз через workflow_dispatch после общей облачной проверки точного head. GitHub
ожидает16Oct00:05UTC (03:05МСК) без lease, SQL, ключей в ожидающем шаге и запросов
к источникам. После00:25UTC выполнение запрещено. Повторяющегося расписания нет.

После ожидания проверяются точный проверенный checkout, успешный qualifying run
и совпадение всех исполняемых файлов со свежим main. Только затем исполнитель
читает свежие phase/fence/status/resume/generation, получает и читает обратно
собственный ограниченный20-минутный RETAINED_HISTORY lease. Чужой lease не снимается.
Восемь GET повторно подтверждают неизменные immutable версии и все settings/crons
двух читателей. Значения секретов не экспортируются.

Проверка использует не более одного обычного RETAINED_HISTORY admission из прежних
двух/сутки,5000R400W,48строк,16bridgeHTTP,40общих GitHub+WorkercontrolHTTP и164whole.
Максимум mutation batches уменьшается на фактический control расход, сохраняя
резерв курсора/освобождения owner. Никаких сбросов/возвратов квот и новых sourceHTTP.

Пул A1–A4 разрешён только внутри этой ограниченной квалификации после точного
подтверждения уже установленной схемы/читателей. Постоянные repository variables
не изменяются; автоматическая ротация остаётся выключенной. Горячие оригиналы
заменяются только после точного durable copy и native preflight, ссылки/статистика
и последние оригиналы монет защищены. Точные post-readbacks и native usage
сохраняются в artifact, собственный lease освобождается.

Успех этого задания не равен завершению плана или выпуску Telegram. Нужно прочитать
его фактический artifact, затем естественный полный отчёт и проверить две монеты.
Достаточный дневной throughput и весь native day ещё требуют подтверждения.
