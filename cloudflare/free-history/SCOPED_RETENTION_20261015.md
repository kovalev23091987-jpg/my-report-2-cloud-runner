# Ограниченный перенос с точной позицией обхода

Это подготовка в прежнем RETAINED_HISTORY: 2 запуска/сутки, до48 строк,
5000R/400W,16bridgeHTTP,40controlHTTP и164wholeHTTP. Флаги остаются выключены.
Все4 разрешённые UTC15 попытки потрачены; эта правка не разрешает пятую.

## Что исправлено

- Корневое окно остаётся128 metadata rows по rowid, без чтения крупных тел.
- Для dispatch binding, recheck, lifecycle и Telegram используются точные
  индексы сохранённой production schema и только ключи текущих кандидатов.
  Отсутствующий индекс останавливает перенос до чтения крупных тел.
- Для namespaces без пригодного индекса остаётся полный ограниченный census;
  переполнение, неизвестная стоимость и новые ссылки оставляют оригинал горячим.
- Те же ключи и ограничение роста повторно проверяются внутри conditional UPDATE.
  Ссылка, появившаяся после копии, по-прежнему защищает оригинал.
- Четыре независимых post-readbacks сохранены; горячие заголовки читаются одним
  batch, точные архивные оригиналы по-прежнему читаются независимо.
- `canonical_cursor=auto` читает последнюю подтверждённую позицию из phase.
  Изменение курсора сохраняется CAS после FINALIZED и известной стоимости.
  Частичный/ошибочный/неизвестный результат не двигает позицию; ручной override
  не подменяет автоматическую позицию. Конец таблицы возвращает cursor0.
- Запись курсора и освобождение owner имеют резерв внутри прежних40controlHTTP.
- Native SQL разрешён только ограниченному lease с префиксом `RETAINED_HISTORY.`.

## Что ещё требуется

Следующий разрешённый native qualification: свежий main/phase/fence,
ограниченный RETAINED_HISTORY lease, `kind=canonical`, `execute=true`,
`native_qualification=true`, `prefetch_private=true`, `canonical_cursor=auto`.
Пул A1–A4 не включать до полного расчёта/проверки соответствующего writer.
Оригиналы должны быть точно прочитаны до и после замены; проверить реальное
освобождение страниц и восстановление сохранения обеих монет.

Структурная ёмкость и эти offline проверки не доказывают native throughput.
Даже номинальные96 переносимых строк/сутки меньше144 плановых canonical+
full_evidence,188 с ручным резервом. Повышение2/day не включено; достаточная
схема длительной работы и полный native day ещё не подтверждены.
