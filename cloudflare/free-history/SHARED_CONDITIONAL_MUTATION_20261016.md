## Новая ограниченная схема

Внутри уже допущенной транзакции максимум8 старых строк группируются только по одному контракту, одинаковому набору исходных полей и одинаковым reference bounds. У каждого оригинала остаются точное сравнение ВСЕХ полей, собственный newer witness, все старые ограничения состояния/времени и защита ссылок. Одно MATERIALIZED чтение на namespace используется общими строками. Для binding полный census охватывает объединение точных publication_id и сохраняет прежний общий предел роста8; переполнение удерживает всю подгруппу. Для contract-индексов область не расширяется на чужие монеты. Глобальные namespaces остаются глобальными.

`RETURNING publication_id` сообщает, какие строки изменены именно данной операцией. Совпавший заголовок другого writer не является нашим переносом. Количество, уникальность и принадлежность ids проверяются вместе с changes; затем каждый заголовок перечитывается и восстанавливается до точного оригинала. Сбой транзакции откатывает всю группу. При неизвестной квитанции успех не заявляется, архивные оригиналы остаются.

Запросы делятся по100 параметрам/100000 SQL bytes **внутри прежней транзакции**, максимум8 строк,6 транзакций и1.4MB wire. Общий wire не может вырасти относительно ранее зарезервированного одиночного представления. Долговечные копии и до4 независимых preflight/post-readbacks сохраняются. Суммарный резерв чтений равен СУММЕ прежних оценок каждой строки; экономия по SQLite не используется как снижение native бюджета.

Основания ограничений: [Cloudflare D1 limits](https://developers.cloudflare.com/d1/platform/limits/). Семантика результата: [SQLite RETURNING](https://www.sqlite.org/lang_returning.html), [D1 prepared statements](https://developers.cloudflare.com/d1/worker-api/prepared-statements/). Возврат ids проверен через сохранённый bridge Worker и RemoteD1 на локальной SQL fixture; новый native путь ещё не квалифицирован.

По умолчанию shared SQL выключен. В recovery tool он разрешён только уже существующей ручной native qualification с pool и обязательным independent preflight; отдельный слот/семейство не создаётся. Постоянные writer/rotation flags не включаются. Это код следующего допустимого измерения, не разрешение запускать его UTC16: оба обычных слота потрачены.
