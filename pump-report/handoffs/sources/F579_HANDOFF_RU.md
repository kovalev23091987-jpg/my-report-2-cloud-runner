# F579 — public optional feeds: один условный qualification proposal

Лучший документальный кандидат — settled funding edgeX V2. Подготовлен ровно один условный bounded actual check: максимум два GET, один криптоактив и две записи. Это proposal, не native admission и не готовый normalized producer. До расходов ROOT должен принять или закрыть смысл сериализации rate и каноническую идентичность. Sample не доказывает эти свойства.

Pacifica/Extended исключены после dedup. ApeX Omni проверен как новый прямой API; прежние ссылки edgeX были только asset-identity news. У Aster ранее изучался signed positionRisk: его не повторяли, проверен новый public funding history/config. Все три направления рассмотрены в пределах общего допуска.

В API edgeX разделены расчётные часы, settlement clock, server envelope и receive time. Интервал передаётся полем записи; противоречивые общие периоды и разные варианты имени pagination-маршрута сохранены. Нормализовать проценты, подставлять общий период, строить funding/liquidation-модель или считать OI направлением нельзя. Published definition даёт размерность rate, но raw JSON scale отдельно не объявлен; эта граница прямо указана в proposal.

Потенциальная полезная область — сохранённый крипто-кандидат 4STOCK из выбранных 550 с прежним ROOT-разбором edgeX listing. Это не текущий native contract join, не подтверждение settlement currency и не текущая таблица покрытия. Котировка/биржа остаются исходными либо NULL с причиной; данные другой площадки не становятся BingX USDT.

Aster оставлен на hold из-за неуточнённого encoding rate и исторических интервалов. ApeX Omni — из-за единиц и роли history timestamps. OI edgeX не получил единицы или собственный as-of; новых future liquidation maps нет.

В F579_OPTIONAL_PUBLIC_FEEDS_FIELD_UNIT_TIME_COVERAGE_V1.json находятся первичные ссылки, поля, units/time, auth/quota и gaps. F579_ONE_EDGEX_SETTLED_FUNDING_BOUNDED_ACTUAL_PROPOSAL_V1.json содержит точные два URL, условия остановки, принятия, стоимость холодного/тёплого чтения и preconditions. Квота V2 не установлена; v1-лимиты не перенесены. Proposal не резервирует бюджет и не даёт право на IO.

Потрачены 10/10 документальных попыток, включая 3/3 отдельных поиска. Native provider/market/metadata, RPC, SQL, Telegram, Worker, deploy и частные captures — 0. Для всех 550 остаётся NOT_CHECKED; проверенных/квалифицированных карт, новых routes/registry votes — 0. Код, imports и runtime tests не менялись/не выполнялись; только локальные JSON/hash bookkeeping.

Полные страницы, цены, аккаунты и ключи в пакет не сохранены. Git blobs и UTF8 SHA256 первичных файлов указаны отдельно; единый commit всей vendor-документации не заявлен. После заморозки выполняются только освобождение аренды и FULL readback с подтверждением в чате. Старые расходы/unknowns/резервы/caps, девять пауз и два OWNER deferrals сохранены.
