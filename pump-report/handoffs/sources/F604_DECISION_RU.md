# F604 — идентификаторы CoinGecko для BingX

CoinGecko явно указывает API ID `bingx_futures` на [странице BingX Futures](https://www.coingecko.com/en/exchanges/bingx_futures). [Список Demo/Keyless](https://docs.coingecko.com/demo/reference/endpoint-overview) включает маршрут `/derivatives/exchanges/{id}`.

Для ROOT подготовлен один запрос: `GET https://api.coingecko.com/api/v3/derivatives/exchanges/bingx_futures?include_tickers=unexpired`. Режим — официальный keyless без ключа; одна попытка, без повторов, перенаправлений и дополнительных запросов; пределы 15 секунд и 2 МиБ. Запрос не выполнялся. Перед выполнением ROOT нужны свежая authority и отдельный фактический допуск по всем бюджетам.

Сохранённая схема F603 содержит symbol, base, target, coin_id, target_coin_id, contract_type и trade_url. Это описание обязательных полей схемы, а не гарантия заполнения для всех 550 инструментов. В схеме отсутствуют native contractId, margin и settle. BingX Futures содержит разные quote-семейства: target=USDT сам по себе не доказывает USDT-M. Внутреннюю привязку можно предложить только при уникальном совпадении с уже принятым native tuple или ранее доказанным первичным alias, с проверкой USDT margin/settle. Неоднозначности остаются UNKNOWN.

[Keyless policy](https://docs.coingecko.com/docs/keyless-public-api) описывает общую динамическую IP-квоту около 10–30 запросов в минуту; дневной и месячный пределы не опубликованы. Для Demo отдельно сохранены 100 запросов в минуту и 10 000 кредитов в календарный месяц. [Pricing FAQ](https://www.coingecko.com/en/api/pricing) устанавливает 1 запрос = 1 кредит. Остатки по нашему IP/аккаунту неизвестны. Переключение режима после ошибки и независимые квоты через wrappers не допускаются.

Результат предполагаемого запроса — только фактически возвращённые идентификаторы, исходные ссылки на строки, хеши, счётчики пропусков и неоднозначностей. Funding/OI/цены и производные BTC/ETH-метрики не используются. Покрытие 550 и текущий CORE не подтверждены. Ошибки 401/403/429, превышение размера, таймаут и неверная схема завершают попытку без повторов.

Грант документации исчерпан: 2 поиска и 4 новых первичных чтения. Новых квалификационных вызовов — 0; счётчик сохранён 23/24, остаток 1. После одной фактической попытки ROOT остаток станет 0 даже при ошибке. LIVE70, исходные расходы, неизвестные значения, резервы, 9 пауз и 2 OWNER deferrals сохранены.
