# Swole BTC: конечный план одного запроса

План `SWOLE_BTC_ONE_PROBE_PLAN_V2.json` использует уже прочитанные официальные developers/methodology страницы и действующий parser. Новый поиск или запрос Swole не выполнялся. Только ROOT после отдельного свежего whole/provider/native/SQL допуска может выполнить один GET `https://swolecharts.com/api/liquidation-levels/BTC` без query, ключа, повторов, смены домена или перехода по redirect. Один исход включает timeout/ошибку/unknown; потраченные/неизвестные расходы не возвращаются. Предложены timeout/deadline 10s и предел ответа 262144 байт через параметр конструктора broker `max_response_bytes`. Это не реализованный аргумент отдельного запроса и не допуск расходов.

Существующий broker уже использует Accept JSON и redirect manual с отказом 3xx. Для пробы нужен ttl_ms=0 и один уникальный probe key; повторно использовать terminal receipt, не делать второй dispatch. Broker не возвращает Cache-Control в нормализованном receipt. При ttl0 повторное кеширование выключено; перед будущим включением обычного TTL ROOT должен сохранить и соблюдать настоящий Cache-Control. Задержка HTTP 10s не заменяет отдельный SQL/whole wall-clock предел. Реальные веса провайдера, SQL, байты и задержка неизвестны до измерения. Старые BingX5 (3 success + 2 unknown) и Telegram239 не обнуляются и не служат новым допуском.

Публичные документы называют маршрут бесплатным, ключ необязательным; это не гарантия фактического доступа, payload или безлимитный расход проекта. Сохранены условия атрибуции, Cache-Control и ограничения повторной продажи raw feed. Статус каждой неизвестной части и причины отказа перечислены в плане.

`sources/swole-btc-route-inactive-v1.json` — минимальный неактивный шаблон для существующих `verifiedSwoleRoute`/`normalizeSwoleMap`. Непроверенные identity/model/venue/market/quote/scale/mapping остаются null. Поэтому действующий валидатор отказывает до IO. Нельзя заменять их строками-заглушками для прохода guard. Текущие 13 registry routes остаются пустыми. Один offline check проверяет шаблон, конечный план и отсутствие вызова broker; не доказывает native response.

После пробы отдельно нужны точная BTC/Bitcoin привязка Swole к проверенному BingX100 underlying, реальный model_version и estimated, source as_of в миллисекундах и возраст ≤300000ms, состав исходных площадок, price quote, реальные long/short bins и их охват, выбранное поле и шкала величины. Документированная версия `est-1.0+hl-2026-09-27` не объявлена версией ещё не прочитанного payload. Даже поле `usd` трактуется только как относительная интенсивность модели. Это внешняя модель, а не открытые позиции BingX или уже случившиеся ликвидации.

Без доказанной сопоставимости с текущей ценой BingX (исходный возраст ≤30000ms, proof, валюта/market/инструмент) зона получает `NOT_FOR_EXACT_BINGX_ORDERS`. USD не превращается автоматически в USDT, multiplier1 не придумывается. Дополнительный запрос цены не входит в лимит одной пробы. Отсутствующий/неполный/устаревший ответ, неизвестная величина и неуспешный допуск карты не задерживают пригодную основную идею.
