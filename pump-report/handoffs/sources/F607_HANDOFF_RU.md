# F607 — два новых исследовательских направления, HOLD до native

Перед просмотром Satori Finance и RabbitX выполнен широкий поиск по всей переданной рабочей папке: текущий проект, старый post-v7 и checkpoint-материалы в MD/JSON/TXT. Совпадений по обоим кандидатам не найдено. Старые source-index и F606 использованы для исключения ранее исследованных линий; локальная новизна не объявляется всемирной. Китайский запрос включён; язык поиска не доказывает страну поставщика. Одноимённые нефинансовые Satori-сервисы отброшены.

Положительная документальная находка — Satori Finance public pair-list. Точные относительный маршрут, поля, классификация fact type и ограничения находятся в F607_PROVIDER_DISPOSITION_V1.json. Это потенциально полезный единый native metadata batch для подготовки отдельных venue-consumers; не карта, не текущая котировка/OI/funding и не готовый производственный маршрут. Контрольная граница: в документации приведён testnet. Production host не подставлялся, образец не выдавался за доступные текущие рынки. Позиционный user API не принят за публичную перепись открытых позиций.

RabbitX остаётся HOLD по authority текущего API-контракта: найденный репозиторий и оглавление не подтверждают production base, доступ и квоты. Неофициальный SDK не запускался, непроверенные домены и сторонние числовые метрики не использовались для выводов о жизненном цикле сервиса. Нельзя объявлять API недоступным только из-за пробелов документации.

F607_ROOT_NEXT_HOLD_V1.json содержит точные недостающие доказательства. Готовых native action = 0; call25 не запрашивается. Прежде чем рассматривать новую фактическую попытку, требуются документальные base/auth/free/quota/schema/clock/identity доказательства, отдельное direct owner exception после исчерпания лимита и фактический общий/provider admission. Публикация каталога сама по себе не даёт coverage выбранных 550.

Израсходованы 3/3 поиска и 6/6 новых первичных чтений. Два чтения завершились timeout/502; они учтены и не повторялись. Полных market/API schema qualification нет. Первичные URL, время получения, тип результата, уровень доказательства и хеши представления — F607_PRIMARY_PROOFS_V1.json.

Новых API/MCP/SDK market/metadata/native calls, SQL/TG/deploy, signup/key/payment, исходных capture-перечитываний, helper-кода и локальных моделей = 0. Квалификации 24/24, остаток 0. F605 identity519/31 сохраняется без переноса в покрытие новых источников. Новых CORE/future-map/recurring routes = 0. Карта необязательна; рабочий сигнал не задерживается. Все расходы, unknowns, резервы, 9 пауз, 2 OWNER deferrals и пауза старого отчёта сохранены.
