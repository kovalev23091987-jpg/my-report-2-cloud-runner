Получены три новых API-направления и одна навигационная зацепка. Это результат ограниченного поиска документации, а не квалификация работающих источников. Постоянная бесплатность hosted API не подтверждена ни у одного; явного требования trial в прочитанном материале GRVT/Defx/Reya не найдено. Новых пригодных карт — 0; проверенных соответствий BingX — 0; все550 остаются NOT_CHECKED для этих направлений. Поиск на японском, арабском, испанском и корейском расширял поиск, но не доказывает страну поставщика.

Все запросы в таблице — предложения для отдельного допуска ROOT, сейчас не разрешены и не выполнены. Даже предложенный один metadata call не даёт разрешения на следующий asset-definition/book/wallet запрос. Для Defx/Hibachi до native вызова сначала нужен отдельный документальный допуск на недостающую схему.

У [GRVT](https://api-docs.grvt.io/market_data_api/) определения дают base/quote/kind и единицы min_size/max_position_size/min_notional; STABLE_PERP включает RWA с USDC. Поэтому нельзя считать любой perp криптовалютой. Funding выражен процентными пунктами с собственным interval_hours; funding_time и create_time документированы в Unix ns. В публичных сделках есть стабильный trade_id, но поле и пример event_time сами по себе не закрывают все часы/единицы. [Официальные лимиты](https://help.grvt.io/en/articles/9636566-what-are-the-rate-limitations-on-grvt):1500/min instrument/mini ticker/ticker,500/min прочие market REST,150 market WS streams и300 subscriptions/min. Это внешние документальные пределы, не новая проектная квота. У book противоречие: prose max10 против enum10/50/100/500, поддержка UNKNOWN.
