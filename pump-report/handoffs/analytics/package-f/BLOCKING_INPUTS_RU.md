# Следующий содержательный шаг: недостающие входы

На сохранённых искусственных данных пакеты E/F завершены в своём объёме. Дальнейшее достоверное измерение точности/полезности не продвинется повторением тех же примеров.

1. ROOT должен устранить два воспроизведённых E-разрыва: сохранять исходную UNKNOWN после возможной отправки и terminal UNSENT FIRST_READY, с неизменными t0/P0/исходным анализом и отдельными когортами. E09/E10 — конкретные строгие проверки; runtime этим чатом не менялся.
2. Нужны реальные сохранённые оригиналы выбранных карточек: входные факты/карта, clocks доступности до t0, analysis SHA256 и версия реализации, исходная версия профиля/правил, квитанция либо журнал возможной отправки/terminal UNSENT. Не заменять отсутствующее backfill-данными или проверенными искусственными fixtures.
3. Нужен зафиксированный заранее план будущего времени holdout и обучения, версии признаков/модели, точный training manifest и границы допустимого доверительного диапазона/ошибки калибровки. F не назначает произвольную модель и не ретроактивно утверждает precommitment.
4. Нужны независимые последующие наблюдаемые волны соответствующих режимов и пригодные исходы по исходным четырём часам, с честным UNKNOWN/coverage. Один актив, один t0 и повторение той же волны в A/D этого не дают. Инженерные минимумы из ТЗ не заменяют проверку качества.
5. Для оценки добавленного блока нужны сопоставимые сохранённые варианты с теми же обязательными данными/исходным временем; для вероятностной проверки — прогнозы, сохранённые до исхода. Старые карточки без прогноза нельзя превратить в подтверждённые вероятности задним числом. Отдельный массовый сбор карт не требуется и не разрешался.

Эти входы должен дать штатный квалифицированный путь ROOT после запуска и сохранения оригиналов. Новые live-вызовы/расписания/массовый сбор из этого чата не выполняются. Пригодная первая версия без численного процента может работать до накопления доказательств. Без новых входов или конкретного нового дефекта дополнительная батарея повторяла бы уже известное.
