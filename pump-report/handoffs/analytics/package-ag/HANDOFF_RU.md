# AGprepare — delta AF и подготовка приёмки actual launch capture

Подготовлены только файлы `handoffs/analytics/package-ag/**`. `AF_DELTA_TO_AD.json` добавляет12 точных delta-записей по исходным ID AD, сохраняя старые prior_status/remaining.296 строк AD и полный719-аудит не перепроверялись, ledger не изменён. AF8PASS используются как ранее завершённое искусственное кодовое доказательство, не nativePASS.

Закрыты в коде конкретные observation-пробелы: самостоятельный consumer3m наряду с5m, отдельные signed acceleration/effort observations, failed-high bars после заранее известного подтверждённого HIGH, величина возврата и OHLC временные/скоростные границы. Новые наблюдения доступны фактическому второму основанию и риску карточки. Полная причинность покупок/поглощения/выкупа и новый stage estimator не заявлены. ACTIVE/WEAKENING/RESUMING остаются прежними proxy; минимальное предложение ROOT — показывать новые наблюдения, а численную существенность/шум/критерий переключения выбрать отдельно только перед изменением classifier. AG не предлагает произвольных значений и не меняет стратегию.

`review-launch-capture.mjs` подготовлен как небольшой pure offline consumer с единственным import `node:crypto`, без автоматического запуска/CLI. Он требует private actual capture, независимых ROOT hashes/original readbacks/exact pin и подтверждённого source-body адаптера. После actual input точный pure core передаётся callback; reader сверяет неизменённый original input/analysis и полную фактическую recomputation, включая card_text, без обновления исходных часов. В вывод попадают только sanitized hashes/reasons/counts/booleans. Missing book/единицы/ссылки не восполняются; stale original не омолаживается. Receipt/SENT/admission/полный550 не доказываются им автоматически.

Точная предлагаемая форма и trust boundary описаны в `INPUT_CONTRACT_PROPOSAL_RU.md`. **Dependency:** ROOT ещё должен подтвердить окончательный envelope и передать фактический private capture с независимыми bindings. Поэтому consumer сейчас UNEXECUTED: kernel imports0, Node imports0, syntax/runtime checks0, tests0, synthetic fixtures0. Отсутствие input не проверялось искусственным запуском. Статическое чтение и хеширование подготовленных файлов не являются функциональной квалификацией.

Новых source research/HTTP/RPC/SQL/Telegram/deploy нет. AFproducer, shared contracts/profile/runtime и старые source пакеты AG не меняет. Расходы/unknowns/резервы/caps,9пауз,2OWNERdeferrals и исходные оригиналы сохранены. После freeze освобождается только own аренда с FULL readback. ROOT может читать готовые файлы/manifest; исходящее сообщение в другой чат не отправлялось. Следующий шаг зависит от actual capture, а не от дополнительной модели, аудита или synthetic проверки.
