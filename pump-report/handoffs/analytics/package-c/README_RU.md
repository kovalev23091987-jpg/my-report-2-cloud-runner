# Точечная аналитическая приёмка C

Основание: ROOT после пакета Б прямо поручил два конкретных исправления. Стратегия +10% от исходной цены за4h не меняется. Общие contracts/profile/runtime/source/registry не изменялись. Пакеты А и Б имеют отдельные уже переданные манифесты; оригинальные байты трёх меняемых файлов сохранены в baseline/*.before.mjs для независимого замораживания ROOT.

1. Для t0 с секундами/мс старый расчёт требовал только полностью внутрипериодные минутные свечи и не мог доказать MISS. Теперь непрерывные закрытые свечи, покрывающие весь период снаружи, доказывают отсутствие достижения, если каждый high строго ниже точной цели. Граничный high на цели или выше остаётся неопределённым, не HIT. Дыра остаётся UNKNOWN. Внутрипериодная положительная точка сохраняет HIT и исключает флаг no-hit.

`coverage.complete` сохраняет прежний смысл точного внутрипериодного покрытия. Для отдельного отрицательного доказательства добавлены `no_hit_period_covered=true`, `no_hit_basis=ENCLOSING_CLOSED_MINUTE_BARS_ALL_HIGHS_BELOW_TARGET`, `basis` с указанием вида доказательства. При одних внешних граничных свечах drawdown_total_pct и drawdown_before_hit_pct остаются null. Неизвестный момент boundary low не становится снижением внутри периода.

Сводка Б минимально принимает этот отдельный тип зрелого MISS; не превращает его в coverage.complete=true. Счётчик enclosing_no_hit_proof_mature_waves отдельный. Голый boolean без правильного basis не принимается. Численная вероятность/успешность по-прежнему null.

2. В короткой карточке не хватало source as-of/давности/модели/ограничений карты, а вероятность не называла оцениваемое событие. Теперь каждая зона показывает исходное время МСК и возраст от event_ts, исходную биржу, модель/версию либо честное отсутствие названия, ограничения и охват. received_ts не освежает карту. Длинные описания ограничены по отображению; полные значения остаются в анализе. Заголовок называет событие +10% за4h и явно говорит, что вероятность ещё не оценена. Это порог события, не численный прогноз вероятности. Прибыль пользователя не заявляется. Ценовые области плана по-прежнему не называются ликвидациями.

Проверки C — только новые целевые случаи из targeted-c.test.mjs. Старые44/25 и97+7 не перезапускались; единый сборочный набор выполняет ROOT. Все примеры ARTIFICIAL/NON_NATIVE, без рыночных вызовов, SQL, Telegram, deploy, cron. Принятая дата/версия ТЗ сохранены.

Не проверены здесь: реальная история BingX для полного четырёхчасового исхода, native provenance, сохранение/доставка того же текста, полезность признаков и калибровка. Для реализации ROOT нужны только три изменённых analytics файла и новый targeted-c.test.mjs; остальные файлы передачи — доказательства и исходные версии.
