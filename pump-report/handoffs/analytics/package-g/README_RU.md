Новые максимальные примеры содержат три области входа, одну область фиксации, выбранные 3+3 зоны, объединения с несколькими компонентами, длинные source/venue/model/version/scale labels и все четыре дополнительных контекста. ## Минимальное исправление

Изменён только renderer в `analytics/index.mjs`:

- Обычная карточка сохраняет прежний полный формат, пока помещается в 4096.
- Сокращение labels учитывает целые Unicode code points и консервативно считает UTF-16 длину. Остаточные непарные суррогаты в готовом тексте приводятся к корректному Unicode.
- При превышении порога сначала резервируются **весь план**, подтверждение/предварительность каждого входа, размер позиции, наблюдаемая отмена, все шесть выбранных ценовых зон, источник/биржа/расчётный либо наблюдаемый характер/модель/часы/ограничения и честный статус/охват карты.
- Подписи зон становятся компактнее; относительная/неизвестная единица не переименовывается в USD/USDT, величина объединения остаётся максимумом, а не суммой. Наличие источниковых ограничений обозначено даже при сокращении.
- Дополнительные объяснения добавляются целыми фразами в оставшееся место; полная структура анализа и findings не удаляются. Для компактного представления есть явная отметка. Нет обрезания хвоста готовой карточки, которое могло бы удалить план или пересмотр.
- Проверяется итоговая граница 4096. Вероятность остаётся null; готовность и торговые пороги не менялись. Новых зависимостей для runtime bundle нет.
