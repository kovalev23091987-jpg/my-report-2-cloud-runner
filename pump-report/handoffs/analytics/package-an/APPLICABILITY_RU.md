# AN — применимость frozen F574

**Готового producer для подключения нет.** F574 даёт два документальных кандидата, новых пригодных OPEN inputs/карт/зон — 0. Нативный допуск из AN не возникает. Вывод основан только на трёх назначенных файлах F574; manifest SHA `c199dfe7087d0db7be3f3c537a85eb8e22da33fce0269a4677ae178b8b8092ba`. Точные входы и проверка байтов — `input-receipt.json`.

**Ближайшая полезная статическая проверка — происхождение Adrena.liquidationPrice.** README перечисляет `getPositionStatus({wallet,rpc,principalToken,positionAddress})` и поле результата, но реализации нет в frozen proof. Это ещё не доказанное опубликованное наблюдаемое поле. SOURCE должен установить, получает/декодирует ли SDK готовое поле протокола, включая документированный view result, либо вычисляет его локально. Официальное происхождение SDK само по себе этого не решает. Для первого варианта сохраняется vendor-estimated threshold, а не факт произошедшей ликвидации; второй остаётся нашим derived результатом по vendor formula. Этот приоритет — выбор следующего доказательства, а не обещание ближайшей пригодности.

У Adrena обязательны подтверждения read-only/signer-free data path, связи SDK/ABI с deployed program и полного position/pool/custody/oracle state. Wallet gate из README нельзя ни игнорировать, ни объявлять доказанным требованием подписи именно чтения без реализации. Нужны native scales и единицы size/collateral/liquidationPrice, crypto underlying и quote/settlement, source generation/context slot/oracle publish time и получение ответа. PDA не доказывает текущую OPEN позицию или стабильный lifecycle при close/reopen. Synthetic commodities pool не является доказательством crypto coverage. Адресов, clocks, текущего бесплатного RPC и census пока нет.

**Perennial — более точный документальный калькулятор, не готовый published liquidation field.** `marketSnapshots` — кандидат на источник состояния; `calcLiquidationPrice` — отдельный локальный расчёт. Если мы запустим официальный helper, методика останется vendor-defined, а конкретный вычисленный нами результат нельзя назвать заранее опубликованным vendor observation. AN его не запускает, формулу и модель не внедряет.

Нужны binding acquisition→snapshot→actual collateral/fees/current and pending exposure→maintenance/oracle version в согласованном блоке, исходные часы и точные Big6/Big18 conversions. `longBelowMargin/shortBelowMargin` — иные margin thresholds. Falsy/missing-input `0n` — default, не нулевая зона. `isActivePosition(status != resolved)` может дать true для missing/closed и не доказывает OPEN; current exposure и pending settlement должны быть различимы. `limitPrice` override не подтверждает текущую позицию.

Payoff units могут быть нелинейными/leveraged. Ни тикер, ни decimals не устанавливают underlying-price threshold, BASE_ASSET/USDT notional, обратное преобразование или factor1. До сопоставления с BingX нужны доказанные native product/underlying, единица порога, quote/settlement/collateral и venue price basis. Это особенно ограничивает применимость Perennial; AN не выводит преобразование из формулы. Read-only protocol init без signer не доказывает бесплатный RPC/graph transport, quota или стоимость одного SDK-вызова. Known-account sample не census, all550 остаётся NOT_CHECKED.

**Flash Trade остаётся на operational hold:** frozen notice указывает wind-down/close-only/force-close, но excerpt без года не устанавливает точную хронологию или текущее число OPEN позиций. Старая формула этого не исправляет. **HMX — NOT_CHECKED:** недоступный docs root и отсутствие схемы не означают UNSUPPORTED.

SOURCE отдельно собирает недостающие SDK/state/transport доказательства. До любого native шага ROOT нужны exact admitted account/market set, endpoint/calldata/measured fanout, текущий free entitlement/quota и отдельные фактические provider/whole/native admissions. Сейчас таких запросов нет.

Код, contracts/context, формат, правила, engine/runtime, маршруты и модель не менялись. Новых source web/provider/RPC/SQL/TG/deploy/captures/tests/replay — 0; AM не повторён. Расходы/unknowns/резервы/9 пауз/2 OWNERdeferrals сохранены. Прежняя own-аренда истекла и не оживлялась; сохранение выполняется по новой 60-минутной FULL-аренде из `authority-renewed.json`. Freeze один; release будет отдельной квитанцией.
