Существующие условия сохраняются. Fact event/received/expiry должны быть доказаны; factUsable и optional usable не превращают строковый timestamp или время загрузки в источник. Текущий профиль: open_interest TTL120000ms, trades30000ms; event_ts≤received_ts и пригодность на analysis time обязательны для использования. Эти TTL не обновляются скачиванием/кэш-хитом. StandX ISO syntax сам по себе не доказывает OI event clock. BloFin ms semantics документированы, но свежесть реальных строк ещё не измерена.

Counting convention не вводится как новый универсальный gate для одиночного подписанного published scalar: неизвестность ограничивает сравнение/агрегирование, а не разрешает додумывать long+short definition. DUSD basis можно оставить непроверенным, выбрав только base-unit OI. Для обоих источников сохраняются native venue/market/asset/quote/settle и точное сопоставление с целевым BingX instrument; одинаковый тикер не binding. Один primary lineage не становится несколькими независимыми голосами.

**Ровно два целевых documentary подтверждения от SOURCE/F577:**

1. **StandX:** что именно означает row time относительно open_interest — является ли он source as-of/sampling clock этого OI, с какой подтверждённой временной границей. Если это только response-generation/load timestamp или точной связи нет, оставить OI clock UNKNOWN. Counting metadata полезна для описания ограничения, но не новый универсальный запрет; DUSD-conversion для выбранного base scalar не запрашивается.
2. **BloFin:** exact route-specific контракт пары size/side — в чём выражен size и означает ли buy/sell сторону агрессора. Подойдут только первичные definitions для этого метода/инструмента; без них quantity/notional/aggressor остаются UNKNOWN. Это один связанный ingestion proof, не повод угадывать множитель или смешивать методы.

После documentary proof ROOT отдельно решает current public/free access, exact identity, actual clocks/coverage, provider/whole/native admission и общую цену. Документальные 50req/s StandX и неизвестная BloFin quota не дают проекту расходный допуск; вечная бесплатность/SLA не требуется. Текущий optional upper2 не увеличивается. StandX даёт лишь venue-specific positioning scalar; BloFin потенциально добавляет venue trade flow, если реально квалифицируем, но не подтверждает поглощение/вход BingX. До такой пользы/цены маршруты остаются выключенными.
