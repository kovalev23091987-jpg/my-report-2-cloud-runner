Perp/swap различаются; swap null — отсутствие, не0. Текущий OI — scalar CONTRACTS/BASE_ASSET/USDT; native USDC не переименовывается. Никаких новых весов/ready gates/вероятности/изменения плана из этих snapshots.

**Дубли и граница карты.** Variational rolling24h USDC volume/indicative RFQ size-tier quotes не заменяют BingX closed windows или standing book depth и не являются future liquidation levels. Stats route не предоставляет OPEN positions. Decibel historical trades/liquidation events не заменяют OPEN account state. Для обоих native REST/SDK/WS/hosted wrappers одной lineage не становятся дополнительными поставщиками/квотами. Exact BingX order-level использование чужой цены требует отдельного venue basis; native funding percentage само по себе такой конверсии цены не даёт. Nado остаётся parked без API/schema, без native proposal.
