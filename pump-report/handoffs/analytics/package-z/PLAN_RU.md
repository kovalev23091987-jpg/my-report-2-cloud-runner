# Z — actual saved-store resolver в существующий W

До патча зафиксированы SHA actual retained writer/journal/delivery/store, W/V и frozen packages. Новый owned модуль analytics/saved-capsule-audit.mjs экспортирует auditSavedCapsules({records,read,as_of_ts,split_plan}); read — только async exact store.get, никакого сканирования/провайдера/глобальной истории. Реальный W auditCohortSample вызывается с явной v2 версией и resolver.

Bounds:≤10 supplied summary rows,262144B входного массива;≤90 фактических точечных read вызовов,≤524288B одного readback,≤2000000B суммарно read и≤2000000B hydrated evidence;≤64 analyses и64 publications одного journal. Повторные ключи кешируются в рамках вызова. Кэш/чтения не выходят за связанные ключи этих10records. Bounds — не native SQL admission и не доказательство физической ёмкости. Overflow завершает весь вызов ошибкой, missing refs остаются явными ошибками W, не исчезают из corpus.

Resolver читает exact summarylink→feature/outcome/savedanalysis/protected refs, actual signal и journal.frozen_anchor. Сверяет выбранную journal analysis/publication запись, card immutable analysis/text/source_input_key и реальный send_started/receipt для исторической publication. Не подставляет latest outcome/publication в старый summary. UNKNOWN подтверждает лишь возможный прошлый send; SENT требует реальной сохранённой карточки/receipt и bounded clocks. Callerflags, guessed IDs, arbitrary external keys и raw error messages не используются.

UNSENT требует actual journal.terminal; W terminal evidence_ref строится как адрес реально прочитанного subrecord, часы копируются. Если terminal отсутствует и есть лишь expired deadline, explicit unbound вместо выдуманного терминального факта; при необходимости ROOT получает минимальный patchproposal для первого persisted expiry terminal, старые строки не повышаются задним числом. Forecast/model/train manifests отсутствуют в actual writer: resolver не ищет и не создаёт их, W вернёт NOT_CALIBRATED/null. Никаких CURRENT/успешности/полезности по availability.

Одна новая интеграционная квалификация использует actual retained writer + OutcomeJournal + MemoryStore + оригиналы + artificial delivery callback. Проверяются реальный SENT/UNKNOWN/UNSENT readback, hashes/anchor/card/receipt missing/tamper/future limits, cache/read/evidence bounds, W current schema и честный split/NOT_CALIBRATED. Accepted W9/V8/T4/X2/ROOT тесты не запускаются. Fake delivery не вызывает HTTP/TG; preload запрещает native network. ROOT runtime/sourcepage/admission не меняются. Handoff сохраняет только безопасные summaries/SHA, без raw/private originals.
