Новая `trade_context.price_response` содержит ровно5 ценовых скаляров по одной и той же пригодной дедуплицированной выборке:

1. `first_price`: цена группы самого раннего event_ts, только если все её сделки имеют одинаковую цену; иначе null.
2. `last_price`: то же для самого позднего event_ts; порядок массива/лексикографический ID не используется как рыночный порядок.
3. `min_price`: минимум цен всех пригодных уникальных сделок выборки, не минимум полной траектории рынка.
4. `max_price`: соответствующий максимум той же выборки.
5. `first_to_last_return_pct`:100*(last/first−1), только если границы однозначны, начало раньше конца и результат конечен; иначе null с `price_response_reason`.

Существующие `buy_usdt`/`sell_usdt` и новый `netflow_usdt=buy−sell` используют те же строки, price*quantity_base с пригодным aggressor_side. Ноль известной стороны означает отсутствие этой стороны только среди этих пригодных строк. Без пригодной выборки суммы отсутствуют, не подставляются0. Отдельная диагностика содержит null/reason, исходное происхождение и счётчики ограничений.

Строка пригодна только при stable trade_id, исходном свежем event_ts≤fact.event_ts≤received_ts≤analysis_ts, положительных конечных price/quantity/USDT amount, BUY/SELL. Единица всего факта USDT_PRICE_BASE_QUANTITY и origin OBSERVED обязательны. Повтор одинакового ID/содержимого учитывается один раз; конфликт любого существенного поля исключает весь ID, даже если одна конфликтующая строка сама непригодна. Строки без ID теперь исключены: Q не может считать их уникальными исполнениями или суммировать возможные повторы. Это уточнение прежнего anonymous fallback; старое D103 доказательство остаётся историческим и не переписывается.

`direction_coverage` описывает только пригодность возвращённых строк; `coverage.full_market_coverage=false` всегда. Coverage сохраняет counts/duplicate/conflict/exclusion reasons и исходный provider coverage без повышения его полноты. Fact status INCOMPLETE без отдельного принятого нормализованного допуска не повышается до USABLE. Неизвестные side/quantity не дают buy/sell или absorption; price-only отдельный агрегат в Q не вводится.

Короткая фраза допускается лишь при конечном first-to-last результате с ненулевым интервалом времени: «В полученной выборке… от первой к последней сделке цена…; покупки…, продажи… Только выборка, не весь рынок». Указываются source/venue, длительность и ограниченность/исключённые строки. Даже SELL+flat, SELL+fall, BUY+rise не становятся поглощением, причинностью или новым состоянием/баллом.
