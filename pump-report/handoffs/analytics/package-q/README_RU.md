`trade_context.price_response` содержит first_price, last_price, min_price, max_price и first_to_last_return_pct. Суммы BUY/SELL и netflow считаются по тем же свежим пригодным уникальным сделкам с доказанными normalized единицами/направлением. Event time, а не порядок массива или ID, задаёт границы. Разные цены на одной крайней временной метке оставляют соответствующую границу и доходность null с ENDPOINT_ORDER_AMBIGUOUS. Одна временная точка не даёт временной доходности. Min/max относятся только к полученным пригодным сделкам.

Stable-ID повторы считаются один раз. Любой существенный конфликт ID исключается до фильтрации прочих полей, включая конфликт с некорректной строкой. Анонимные строки теперь исключены: их уникальность не доказана. Это целевое исправление прежнего anonymous fallback; исторический D103 с суммой двух неидентифицированных строк не является правилом Q и не переписан. Пробелы, исключения, дубли и конфликты отражены отдельно в coverage. ALL_RETURNED_TRADES означает пригодность возвращённых строк после дедупликации, не полный рынок; full_market_coverage всегда false.

Без пригодного normalized факта нет trade_context и нет нулевых сумм вместо отсутствующих. trade_diagnostic содержит null/reason и исходное происхождение. Без пригодных quantity/aggressor не формируются BUY/SELL; price-only агрегат не вводился. INCOMPLETE не повышается автоматически в USABLE. Переполнение notional/sum/return не превращается в известный результат.
