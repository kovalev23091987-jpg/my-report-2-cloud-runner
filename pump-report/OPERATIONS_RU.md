## Команды после production-приёмки

Запускать из папки проекта с `pump-report/`. Локальный ключ читается из защищённой игнорируемой папки `.private`, его значение не печатается. Результаты по умолчанию сохраняются приватно; пригодная карточка выводится текстом.

```sh
node pump-report/runtime/manual-cli.mjs manual BTC
node pump-report/runtime/manual-cli.mjs manual 'Сделай памп по BTC'
node pump-report/runtime/manual-cli.mjs result REQUEST_ID
node pump-report/runtime/manual-cli.mjs summary 40
node pump-report/runtime/manual-cli.mjs health
```

При обрыве ответа сначала искать результат по сохранённому request_id. UNKNOWN-доставка не пересылается автоматически. Ручная проверка доступна круглосуточно; автоматический поиск, автоматическая статистика и рассылка работают только с10:00 включительно до20:00 исключительно по Москве. Отсутствие карты не блокирует пригодный самостоятельный план и обозначается явно.

Просмотр результата и сводки использует отдельный LOOKUP-конверт500R/30W, максимум10 в день. Он не расходует шесть MANUAL slots; резерв каждого полноценного manual остаётся5000R/300W, независимо от малого размера LOOKUP. Это пределы допуска, а не измеренные средние расходы. Сводка хранит накопленные счётчики всей принятой истории. Параметр40 ограничивает порцию обновления, а не общее число волн. При незавершённом переносе или созревании сводка явно обозначает неполноту; следующий проход продолжает сохранённый cursor. Текущий запрос не перечитывает все исторические записи. Исходные карточки и наблюдения сохраняются.
