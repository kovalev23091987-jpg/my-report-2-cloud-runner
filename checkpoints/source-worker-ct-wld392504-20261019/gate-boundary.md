# Что означает NO_USABLE_GATE_METRIC_REQUIRING_BINDING здесь

Optional `bindGateOfficialAssetIdentity` не является общим source gate. После проверки exact HTX token reference он выбирает только Gate rows с `asset_identity_verified!==true`, alias_verified, закрытым venue observation, свежим source clock и без error. При пустом списке возвращает сохранённый код NO_USABLE_GATE_METRIC_REQUIRING_BINDING **до** нового db_admit/reference reader/request. Это не сообщение провайдера и не HTTP failure.

У обеих новых монет четыре stored normalized rows имеют asset_identity_verifiedtrue, identity/fact CLOSED, decision_usabletrue. Их source-role audit пригоден. Код совместим с пустым optional filter: новое HTX/Gate same-chain binding этим строкам не потребовалось. Не надо ради NOT_CLOSED в оболочке optional return делать дополнительные Gate HTTP, понижать пригодные строки или повторять принятый535 diagnostic test.

В native Worker есть более ранний `promoteCorroboratedAssetIdentity`, использующий `verification.asset_identity` и corroborated exact base/venue checks. Конкретный prior proof branch по этому запуску не сохранён в семи компактных JSON. Label EXPLICIT_ASSET_IDENTITY означает сохранённый true flag в inherited identity; он не восстанавливает original API envelope, exact earlier authority return или independent project/token proof. Current code показывает возможный путь, но не является выполненной трассой historical input. Здесь prior method/первое основание оставлены UNKNOWN/NULL.

Отдельный факт Gate spot N12 не равен этим четырём derivatives metrics. Native code `gate-flow-collector` строит bounded N12 sample из тех же N05 pages даже когда полная240-minute reconciliation не закрылась. `gate-n12-bounded-trade-sample` требует exact asset/reference/receipt/page binding, сохраняет original trade clock, whole_window_coverage_provenfalse и neutral0. В report сохранены actual N12 fact IDs/physical roots/raw hashes/known-by/5m bounds/manual render, но не underlying original page/reference arrays. Это достаточная граница **сохранённого факта/consumer**, не новый raw replay или source admission.

N05 PARTIAL_FOUR_HOUR_FLOW и прежняя priority-history запись Gate NOT_CLOSED не отключают текущие полезные291/251 N12 trades. История относится к прошлому route/role; missing statistics0 не означает broken provider. Два блока используют один shared5HTTP envelope; обе Gate роли остаются одним Gate origin.

Нового потерянного полезного факта, неверного Gate отказа или минимального shared fix исходные доказательства не показывают. Неизвестны точные raw reasons полного Gate4h и actual earlier identity authority. Нужны уже сохранённые exact native envelopes/cache payload именно этого run, если они появятся; старые архивы другой монеты/часов этого не заменяют. Новые запросы/readers/probes не выполнялись.
