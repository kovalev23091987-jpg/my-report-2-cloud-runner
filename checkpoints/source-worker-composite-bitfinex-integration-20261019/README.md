# Единое предложение: исходные часы N12 и Bitfinex USD → N10

Патч `shared-integration.proposed.patch` рассчитан на actual main `0911097a469b78a2d11e745141544fd0cf7a06a4`, уже содержащий Kraken514. Свежие guards отдельно прочитаны на `6f8586f02ebf5ab75bae63720b08bd1b7b3c494f`. Все изменения shared runtime находятся **только в patch artifact**. Файлы production в этой ветке не меняются. Координатор применяет/квалифицирует предложение отдельно. Секреты для локальной проверки не нужны.

Две зависимости скопированы побайтно из frozen512/515: `n12-composite-first-known.mjs` и `bitfinex-n10-price-path.mjs`. Их прежние40/34 теста не запускаются. Новый небольшой provider-specific memory module находится в `proposed-files/`, остальной код использует настоящие функции main. Полная копия generic context не создаётся и не коммитится; временная сборка для теста копирует неизменённые исходники actual main и применяет8-file patch внутри этого checkpoint, затем удаляется. Старые Kraken25+1 и иные suites/probes не запускаются.

Предложение содержит:

- Bitfinex N05: private nonenumerable capsule на **возвращаемой копии** компонента до optional cache write; cache HIT сохраняет original `cache_observed_ts/cache_expires_ts`. Payload/key/INSERT и N12 не меняются. При ошибке cache пригодные N05/N12 и memory-контекст сохраняются; unknown не разрешает дополнительных SQL/source запросов.
- N10: отдельная Bitfinex memory branch без SQL, после прежних фактов. Bitfinex не занимает пятый group и не вытесняет существующий Kraken/legacy group. Старый `.slice(0,4)` и весь SQL loop остаются побайтно прежними, как и Kraken-модули/capsule/N12. Сохраняются approved105 и требования уже полученного свежего точного HTX spot с15 закрытыми native минутами. HTX здесь даёт guard присутствия рынка, **не** USD/USDT-сравнение.
- Новый neutral USD metric с compact producer-receipt validation, source/first-known/expiry и native15 OHLC. Полные raw executions перепроверяются при подготовке; compact-проверка не выдаётся за независимый native cache/wire ACK. USD/USDT FX, HTX gap/agreement, entry/target/score/coverage effect отсутствуют. Guard нового DTO16KiB ограничивает только новый тип, не меняет источник/общий budget. Полный raw payload в DTO не попадает; private capsule держит ссылку на существующий payload до900000байт.
- N12: одно `composite_first_known_ts=max(original first_known)` для точно представленных IDs; неполные/чужие/невалидные mapping/clock дают NULL. Исходные outer HTX source/observed, windows/expiry и счётчики фактов сохраняются. Manual и Telegram receipts вычисляют metadata по своему набору представленных компонент, после прежнего Telegram-фильтра.
- Manual/Telegram: новая строка Bitfinex в существующем дополнительном контексте. Brief получает только узкую проверку этого exact N10 metric, а прежние лимит строк,1800 символов и порядок выбора не меняются. Фраза «в долларах США» сохраняет единицу после существующего удаления буквенных USD/USDT. Общая форма, strategy/weights/70/паузы неизменны.
