# Центральная квалификация этого предложения

`verify-package.py` предназначен для frozen proposal-ветки: он временно собирает actual0911097a+patch, проверяет untouched source spans и выполняет15 новых cases. Для одного нового центрального affected batch использовать **только** `joint-integration.test.mjs` из этого пакета вместе с новыми TTL cases.
