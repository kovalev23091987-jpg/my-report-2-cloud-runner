# Новая отдельная волна после поздно обнаруженного пробоя

Статус: предложение, код и стратегия не изменены. Основание — BZ44 и неизменяемый actual14 SHA256 96ef9124d3b20301dddb1dafead6db47f30760ea18f5bbc6c4ce95f16c1d9eaf.

У IDOL закрытая свеча 13:08–13:09 МСК нарушила прежнюю базу0,013643. Данный факт получен15:13:10.806, отмена записана15:13:13.145. Знание бота раньше получения не доказано. Отмена прежнего плана корректна. Существующий selector допускает новый seed только после времени записи отмены; отдельные новые импульсы, возникшие между13:09 и15:13, исключаются. Наличие среди них пригодного сигнала ещё не доказано.

Предлагаемое уточнение: разрешить рассматривать отдельный новый импульс целиком после закрытой свечи доказанного пробоя, уже известный на текущий момент. Старый CANCELLED план и все его исходные записи сохраняются. Новая волна получает отдельную identity, ссылку на предшественника и раздельные event/known/decision clocks; никакой отправки задним числом.

Для этого нового post-breach пути фиксировать lifetime_anchor_ts=закрытие нового исходного импульса, expires_ts=lifetime_anchor_ts+4ч. Фактическое создание и получение остаются своими текущими timestamp; позднее обнаружение не добавляет новые4ч. Окно поиска240мин не увеличивается. Повторные проверки не меняют anchor/expiry. Старые активные и терминальные волны не мигрируют и не оживляются; ветка EXPIRED сохраняет исходную границу expiry. При отсутствии полного доказанного пути/cause остаётся прежняя консервативная граница.

Сохраняются закрытый рост20%/24ч или10%/5/15/60мин, объём2, ликвидность700–3000, самостоятельный план и минимум10% полной позиции, optionalкарта, исключенияBTC/ETH/FX/RWA, все caps/unknowns/holds/manual3/старые паузы. Это уточнение не доказывает READY для IDOL. До кода нужны прямое решение владельца и boundedaffected-квалификация; новые SQL/market/TG этим документом не разрешены.

Вопрос владельцу необходим из-за его прямого ограничения не менять согласованные решения самостоятельно. ТЗ не задаёт event/observation границу и lifetime такого нового сценария; предложенное правило делает их явными.
