Владение файлами: SOURCE — `sources/**`, `tests/sources/**`, `handoffs/sources/**`; ANALYTICS — `analytics/**`, `tests/analytics/**`, `handoffs/analytics/**`; ROOT — остальные общие файлы. Каждый префикс расположен внутри `pump-report/`. Предложение общего изменения передаётся ROOT, самостоятельно чужие файлы не изменяются.

Один фактический ответ используется всеми тремя чатами. Один связанный пакет заканчивается одной необходимой проверкой и frozen-передачей; принятый аудит и старые suites без конкретного дефекта не повторяются. На время финальной сверки пакета ROOT сохраняет стабильную ветку. Guard bytes проверяются в коде; в контекст выводятся краткие SHA/owner/expiry, не многомегабайтная история. Immutable cache допустим только после совпадения blob SHA со свежей authority.
