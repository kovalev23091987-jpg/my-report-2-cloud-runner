# Продолжение «Мой отчёт 2» в облачной среде

Этот файл готовит запуск. Он сам не запускает агента. Задания сканера и агент, который меняет код, выполняют разные работы.

## Настройка среды

1. На сайте ChatGPT или в приложении на компьютере открыть Settings → Codex Cloud → Environments → Create environment.
2. Выбрать `kovalev23091987-jpg/my-report-2-cloud-runner` и подключить GitHub, если доступ ещё не выдан.
3. Попросить подготовить Node.js 24, Python 3, git и unzip. Для обычных проверок использовать сохранённые архивы. Для сборки зашифрованного runtime нужен доступ к существующему `REPORT2_PAYLOAD_KEY`; значение вводить только в настройках секретов. Секреты GitHub Actions сами в новую среду не переходят. Можно запускать уже проверенные workflows через разрешённое подключение GitHub, сохраняя их бюджетные ограничения.
4. Дождаться отчёта подготовки и проверки среды, сохранить и нажать Publish.
5. Выбрать Work in → Cloud, эту опубликованную среду и отправить задание ниже. На телефоне выбрать опубликованную среду в Codex.

Облачная задача может продолжаться, когда компьютер выключен. Доступность среды на конкретном аккаунте надо проверить в интерфейсе. Команда `/goal` официально описана для приложения на компьютере, CLI и IDE; поддержку этой команды в облачной среде не считать подтверждённой только по наличию Cloud. Постоянная цель продолжает работу между шагами в пределах доступных ресурсов и может остановиться из-за лимита, ошибки, паузы или отсутствующего разрешения.

## Задание для запуска

```text
Продолжай «Мой отчёт 2» в текущем репозитории до проверенного выполнения всего неотложенного ТЗ. Не жди моих команд после отдельных исправлений. Работай крупными связанными блоками.

Сначала разреши свежий main и прочитай по его точному SHA AGENTS.md, REPORT2_CURRENT_GENERATION.json, MY_REPORT_2_STARTUP_CONTRACT.md, checkpoints/CURRENT_PROJECT_STATUS.json, checkpoints/FULL_OWNER_TASK_REGISTER_20261007.json, checkpoints/CLOUD_PHASE_STATE_20261004.json и audit-fixes/source-optimization-20260930/execution-lock.json. Продолжай с последней сохранённой точки, не со старого PR. Перед изменениями получи собственный ограниченный lease через CAS и прочитай его обратно. Не продолжай при потере lease. По окончании освободи только свой lease.

Доведи оставшиеся 86 требований и 24 задачи владельца, учитывая уже доказанные результаты и явные отсрочки. Сохраняй 119 контрактов/102 актива/3 семейства, ограничения inverse/delivery, порог70, правила входа, свежести, направления и сценария, расписание40/5мин, исходные TTL, caps, reservations, manual reserve и утверждённые формы Telegram. Nansen и exact raw24h отложены; полный N05 240мин остаётся обязательным. Отдельное наблюдение FIL не возобновлять.

Не обходи неизвестный расход D1 за 2026-10-09, не сбрасывай журнал и не повторяй исчерпанный cold archive pool. До измеренного допуска работай с сохранёнными исходными данными и кодом. Следующий календарный день сам по себе не доказательство исправности.

Проверяй источник → идентичность → пригодный факт → потребитель → один свежий отчёт → утверждённый Telegram SENT/message_id того же run/snapshot. Отделяй тесты от фактического ENTRY, нейтральные блоки от ненулевой оценки, реальные ликвидационные позиции от расчётных уровней, сохранённую историю от текущих данных. Не подменяй данные HTX архивами другой площадки. Не создавай события рынка и статистическую выборку ради закрытия ТЗ.

После каждого связанного блока сохраняй код, exact head/run/artifact digest, результаты и следующие действия в репозитории. Обновляй текущий статус и phase без противоречивых сводок. Не объявляй готовность по одному тесту, зелёному job или количеству PR. При внешней блокировке выполняй остальные доступные задачи; когда допустимых действий больше нет, сохраняй точную причину, условия возобновления и честный список открытого. Не обещай фоновый процесс, который фактически не запущен.
```

В интерфейсе с поддержкой `/goal` этот текст можно задать как постоянную цель. В облачной среде сначала убедиться, что задача запущена и отображается выполняющейся. Текст инструкции не равен активному заданию.
