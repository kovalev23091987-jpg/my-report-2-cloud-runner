# Протокол до callable: исходные часы scan fallback относительно read-asof

Это один новый связанный TEXT-пакет market-history-reader.mjs, два существующих fallback пути. Семантика не исполнялась. Основание — новый статический контрпример на существующем сохранённом входе, а не инцидент production или повтор старой квалификации.

В readMarketHistoryForContract supplied now_ts задаёт end=now. readScanFallback выбирает scan_runs по ts_bucket BETWEENstart/end, но возвращает ts=finite(scan.ts) без проверки исходного ts против end. readMarketHistoryTargets аналогично выбирает ближайший bucket и не проверяет row.ts относительно now. Writer сохраняет ts=scan.timestamp, а bucket=floor(scan.timestamp/300000)*300000. Это исходные часы наблюдения Stage0, не bucket, D1 ACK или provider body-completion.

Факт native утечки в старом запуске не заявляется; исторический контрпример использует оригинальный sourceclock, не выдуманные provider bytes.
