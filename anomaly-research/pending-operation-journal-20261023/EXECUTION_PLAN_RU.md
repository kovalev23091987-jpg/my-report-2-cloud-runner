# Передача ROOT

1. Full-byte сверить пакет и declared beforeSHA actual runner. Применять только proposed target или его точный patch в ROOT-owned подготовке. Если shared runner изменился — сначала новый целевой delta; не применять WIP/исторический patch целиком.
2. Единственный callable находится в connected.mjs и ничего не запускает при import. Проверить target/unchanged dependency pins до app imports. Нужен applied current-generation/files/runner-main.mjs по afterSHA; ни MAIN, ни SQL-schema, ни privateruntime extractor не требуются для этого component.
3. Выполнить ONE NEW component в центральной affected qualification. Сохранить returned JSON либо error.partial_result сразу до assertion/следующего шага.12/32 — prepared counts, не фактический PASS и не число NodeSPEC. Не повторять старые accepted anomaly/kernel/gate cases.
4. После успешного common ROOT отдельно решает source→assembled installed caller binding и native launch prerequisites. Этот пакет их не закрывает. Production policy/schema/defaultOFF не включать как часть qualification.
5. Реальное использование требует доверенной первоначальной записи и независимо сохранённого expected SHA/identity, неизменяемых private file+claims на actual persistent workspace и current parent admission. INITIALIZE_EMPTY нельзя оставить обычным значением для каждого нового job. Потеря файла/меток, новая execution identity, конфликт или неизвестный исход означают STOP. Нельзя пересоздавать пустой журнал либо менять opid.
6. Полный prepared/known reply находится только в private local file/неоднозначной .next; ordinary metadata artifact содержит только hashes. Платформенный защищённый carrier, recovery после настоящего kill/powerloss и изолированное native readback/cost ещё должны быть квалифицированы ROOT. Не выдавать fsync за native durability/commit ACK.
7. Только ROOT меняет общие файлы/статусы/production. THIRD публикует ownprefix PR/frozen head, не выполняет deploy/MAIN/manual/TG/provider/nativeSQL, не меняет existing limits/pauses/unknown или два OWNER deferrals.
