`verifyReadJson` фиксирует marker только после полного наличия входных байтов, совпадения SHA и завершённого JSON.parse. Marker содержит область входа, raw ref, uncompressed body SHA, время начала локальной обработки и verified-at, основание часов, ref/hash verification receipt и отдельные full-read/hash-match/parse-complete признаки. В `witness.json` сохранены сами receipts. Их `receipt_sha256` — SHA256 компактного `JSON.stringify(receipt)` внутри marker envelope; это проверка связности, а не аутентификация источника или durable native ACK.

Для AAVE прочитан целиком настоящий сохранённый raw JSON body с проверкой исходного compressed/uncompressed SHA. Marker относится именно к этому телу. У BTC проверяется производная исследовательская карточка: marker честно подписан `BTC_DERIVED_RESEARCH_SAMPLE_LOCAL_READ`.
